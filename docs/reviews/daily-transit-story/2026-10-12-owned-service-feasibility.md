This app has not been migrated.** On October 12, read-only requests to `https://patternlike-calc.fly.dev/health` and `/v1/engine` both returned HTTP 200. Health reported `ok: true`, `ephe_ok: true`, Swiss `2.10.03`, wrapper `sweph@2.10.3-7`, and production AGPL mode. Metadata named file-set version `se-2.10.03-1800-2399`, `SEFLG_SWIEPH`/`SEFLG_SPEED`, tropical/geocentric positions, Placidus primary houses and explicit Porphyry fallback. These are service-reported fields, not an independent attestation of the deployed binary or numerical accuracy.

Local `/home/ubuntu/patternlike-app/apps/calc-stub` contains the engine, authenticated HTTP routes, a Docker image, and ephemeris downloads pinned by commit and file hashes. The repository's `fly.toml` names `patternlike-calc`, and its API production configuration points to this Fly hostname. The source currently implements `/v1/calculate`, `/v1/cycles` and `/v1/daily-sky`; it does not implement this app's `swiss-transit-episode/1` response. No authenticated calculation or member birth-data request was made for this check.

The practical owned route is to reuse those engine and deployment components in an isolated service/version for this app, complete its chart/source adapter and transit-episode calculation, then qualify both against the existing requirements. Natal chart/anchor evidence and timelines must share the actual source identity. Existing saved charts must be recalculated through an explicit migration path; they cannot be relabeled as having used the new service. Placidus provenance and fallback suppression remain required.

The [earlier source review](2026-10-12-source-discovery.md#owned-calculator-inspected-read-only) identifies the algorithm differences: retained brackets/residuals, station-connected closure, separate orb windows, quincunx, tangent omission and bounded scanning. The online health response does not close those gaps. The required numerical qualification remains separate from the already-passing writing gates.

The owned service is configured for AGPL and has a source-offer decision in its repository. Swiss Ephemeris offers [AGPL or a professional licence](https://github.com/aloistr/swisseph/blob/master/LICENSE); its current [price page](https://www.astro.com/swisseph/swephprice_e.htm) lists the professional unlimited licence at CHF 700. Reuse must preserve applicable licence/source obligations; no purchase, licence change, new deployment or production configuration change was made. No specific hosting cost is claimed by this check.

The operator is considering the provider inquiry, calculation from hosted positions, and the owned-service route. This record does not select one. Both candidates remain inactive; combined content `0.7.1` is staged and its writing review is passed.
