# Regression evidence

All runs used intercepted local transport. No live provider requests were made.

- Before the qualifier implementation, `node --test tests/reading-context-qualifiers.test.mjs` ran 15 checks: 8 passed and 7 failed as assertions. All three exact second-pilot failures were incorrectly accepted. Added `often increases` coverage then exposed a further non-`ly` adverb gap before it was fixed.
- Before the voice projection change, both tests in `tests/reading-context-voice.test.mjs` failed on the version-2 brief. They require source summaries in separate controls, complete source conditions and parents, request isolation, and unchanged original benchmark acceptance.
- Independent code review reproduced a further incorrect acceptance: `An extra check or another version can easily slip into the larger piece of work.` I2's destination phrase incorrectly licensed the extra-check ease claim. The exact regression failed before the tighter source-clause anchor check. A second exact RED case exposed an embedded `for this effort` keyword borrowing the same license; the final check requires the complete short pre-adverb clause lead to match the source anchor. Positive controls keep both supported I2 effort/ease formulations accepted.
- After the fixes, all 81 focused context checks pass. They include the five original authored benchmarks, both newly edited bodies, the five actual saved pilot responses replayed locally, lossless rejection, complete fallback, single attempts and ordinary routing controls.

These results establish validator and request behavior. They do not score new generated writing.
